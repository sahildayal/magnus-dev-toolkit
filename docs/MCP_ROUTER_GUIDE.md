# MCP Router Guide

The mcp-router is an MCP server that acts as a meta-router.

## How it scores
`Score = (Capability Match × 40%) + (Keyword Match × 30%) + (Cost Efficiency × 20%) + (Budget Available × 10%)`

## How to use
Pass a detailed `task_description` to the `recommend_mcp` tool. It will return the recommended MCP along with budget statuses.
