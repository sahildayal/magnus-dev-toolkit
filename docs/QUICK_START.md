# Quick Start Guide

## Installation
Run this one command in PowerShell:
```powershell
powershell -c "irm https://github.com/sahildayal/magnus-dev-toolkit/raw/main/scripts/install.ps1 | iex"
```

## First Run
After installation, open your CLI (e.g., `gemini`, `claude`, or `codex`).
All 11 MCPs will be ready to use!
