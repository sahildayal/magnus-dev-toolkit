# Architecture

Magnus Dev Toolkit consists of:
1. **Bootstrapper:** Installs 40+ tools via Winget and npm.
2. **MCPs:** Auto-configures 11 core MCPs (GitHub, PostgreSQL, Docker, Playwright, etc.).
3. **mcp-router:** An intelligent MCP that recommends the best MCP for your tasks based on Capability, Keywords, Cost, and Budget limits.
